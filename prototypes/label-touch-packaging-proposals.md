# 내포장·외포장 라벨 터치화면 제안

2026-09-15 계근중량 추가 요청을 반영한 **검토용 시안**입니다. 운영 중인 `label-print.html`, 원클릭 인쇄, 출력이력 저장 및 생산일보 전송 로직은 수정하지 않았습니다.

- 기준: 1280 × 1024 터치 모니터. 기존 `label-touch-proposals.html`의 1안 균형형(왼쪽 작업목록·계산기 / 오른쪽 출력)을 공통으로 사용합니다.
- 1안: 균형형. 오른쪽 상단에 현재 계근중량을 표시하고, 아래에 내포장·외포장을 나란히 둡니다.
- 2안: 작업 분리형. 왼쪽 작업목록과 계산기 사이에 계근중량을 표시하고, 오른쪽에 내포장·외포장 출력 영역을 위아래로 둡니다.
- 3안: 계근 집중형. 상단 계근중량 숫자를 더 크게 표시하고, 하단에 큰 출력 버튼 두 개를 나란히 둡니다.
- 공통: 내포장(진공지)은 생산 집계 제외, 외포장(박스)만 생산량에 포함. 내포장·외포장에 각각 **고정중량 / 계근중량** 선택 버튼이 있습니다. 고정중량은 각각의 중량·매수를 기억하며 숫자 터치 시 숫자판을 엽니다. 계근중량은 현재 저울 예시값을 적용하고 중복 계상 방지를 위해 **계근당 1장**으로 제한하는 제안입니다. 기존 라벨 인쇄 서식은 유지합니다.
- 일반 버튼 높이 64px(시안 조정 60~64px), 중량 모드 버튼 52px, 계산기 키 약 76px(2안 약 56px), 출력 버튼 106px 이상입니다. 좁은 미리보기 화면에서는 읽을 수 있도록 재배치합니다.

시안의 출력 수·생산량·계산기는 메모리 내 예시이며, 창을 새로고침하면 초기화됩니다. 내포장 인쇄 수는 작업 확인용 표시일 뿐 생산 실적이 아닙니다. 저울 설정 창의 COM2 / 2400 / 7E1은 현장 확인값을 안내하는 것으로, 이 시안에서는 장치를 열지 않습니다. 실제 인쇄·서버 요청·영구 저장은 없습니다.

현재 계근중량 또는 저울 설정 버튼을 눌러 **시연 중량 / 안정·흔들림·연결 끊김**을 바꿀 수 있습니다. 첫 화면의 2.48 kg은 예시이며 실제 수신값이 아닙니다. 계근 모드의 라벨 적용 중량은 안정되고 0보다 큰 경우에만 표시·출력할 수 있습니다. 흔들림·연결 끊김·0 kg이면 적용 중량을 대기로 바꾸고 계근 출력 버튼을 비활성화합니다. 고정중량 출력은 저울 상태와 별개로 유지합니다. 출력 버튼을 누른 순간의 안정 예시값만 해당 출력에 사용하며, 재출력은 이후 저울값이 바뀌어도 이전 라벨의 중량을 유지합니다.

실제 연동 시에는 수신 중단/오래된 데이터 판정, 단위·안정 신호 해석, 용기무게 처리 여부를 확인해야 합니다. 현재 화면은 저울 표시값을 가정한 UI이며 순중량이나 용기 공제를 구현했다고 간주하지 않습니다. SM이 포트를 사용 중이면 같은 COM2를 동시에 여는 방식으로 연결하지 않습니다.

선택한 안을 운영 화면에 적용하는 다음 단계에서는 내포장/외포장 구분을 서버 저장·생산일보 집계·재출력까지 일관되게 처리해야 합니다. 기존 출력이력은 이미 생산량으로 사용 중이므로 외포장으로 간주하는 하위호환 처리가 필요합니다. UI 시안만으로 운영 데이터 집계가 변경되지는 않습니다.

검증: `node tools/test-label-packaging-proposals.cjs` (Playwright 필요, `CHROME_PATH`로 브라우저 경로 지정 가능). 내포장 집계 제외, 외포장 누적, 독립 고정/계근 모드, 안정값 적용, 계근 1장 제한, 흔들림·연결 끊김·0 kg 출력 차단, 이전 중량 재출력, 터치 숫자판, 계산기, 작업별 상태, 생산완료 시연, 미리보기, 1280×1024 경계 및 1024/736/320px 반응형 배치를 검사합니다.
