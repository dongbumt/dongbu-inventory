# 라벨 터치화면 — 선택한 2안 수정안

2026-09-15 사용자가 선택한 **2안(작업 분리형)의 검토용 시안 원본**입니다. 이후 운영 적용 요청에 따라 `label-print.html`에 연결했습니다. 이 시안 자체는 여전히 예시 데이터만 사용하며 실제 인쇄·저장은 하지 않습니다. 운영 동작과 현장 연결 방법은 `../label-touch.md`를 참고하세요.

## 화면 배치

- 기준: 1280 × 1024 터치 모니터. 기존 동부엠티 ERP 디자인과 회색 계열을 유지합니다.
- 현재 계근중량을 **오른쪽 위** 제품 정보 옆으로 이동했습니다. 2.48 kg은 예시이며 실제 수신값이 아닙니다.
- 왼쪽 작업지시 목록은 왼쪽 본문 높이의 52%로 확장하고 예시 작업 4건을 표시합니다. 계산기는 왼쪽 아래에 유지합니다.
- 오른쪽은 위에 내포장(진공지), 아래에 외포장(박스)을 배치합니다. 내포장은 생산 집계 제외, 외포장만 생산량에 포함합니다.
- 일반 버튼 높이 64px(시안 조정 60~64px), 중량 모드 52px, 계산기 키 약 51px, 출력 버튼 140px 이상입니다. 좁은 화면에서는 세로로 재배치합니다.

## 외포장 선택 재출력

하단 **재출력** 버튼은 현재 작업의 외포장 출력이력 팝업을 엽니다. 작업명·LOT·출력번호·시간·당시 중량·재출력 횟수를 보여줍니다. 4건씩 이전/다음 페이지로 이동하며 여러 라벨을 선택할 수 있고, 선택은 페이지 이동 및 미리보기 후 복귀 시 유지됩니다.

**선택 N장 재출력**은 선택한 기록의 당시 라벨 내용과 중량을 사용합니다. 현재 저울값이나 고정중량을 바꿔도 과거 기록에는 영향이 없습니다. 재출력으로 생산량·외포장 실적·출력이력 건수는 증가하지 않습니다. 내포장 기록 및 다른 작업의 외포장 기록은 목록에 포함하지 않습니다. 이력이 없는 작업은 빈 목록 안내를 표시하며, 전송 완료한 작업도 재출력할 수 있습니다.

## 실제 라벨 미리보기

내포장/외포장 **라벨 미리보기**와 이력별 **미리보기** 모두 실제 인쇄에 사용하는 전체 라벨 서식을 보여줍니다. 제품명, 원산지, 제조·소비기한, 중량, LOT, 원재료, 보관방법, 안내문구, 제조원, HACCP·재활용 마크를 포함합니다. 데이터는 시안용 예시입니다.

`tools/build-label-proposal-preview.cjs`가 운영 `label-print.html`의 라벨 본문 함수와 `label-print-document.js`의 라벨 CSS, 기존 마크 파일을 그대로 복사해 시안의 지정된 블록만 갱신합니다. 운영 파일이나 마크 원본은 변경하지 않습니다. 70 × 100 mm 용지, 우측 안전 여백을 적용한 67 × 100 mm 내용 영역을 확대 표시합니다. 프린터의 실제 출력 품질까지 재현하는 것은 아닙니다.

```text
node tools/build-label-proposal-preview.cjs
node tools/build-label-proposal-preview.cjs --check
```

## 계근·출력 시연 범위

내포장·외포장은 각각 **고정중량 / 계근중량**을 선택합니다. 고정중량의 중량·매수는 각각 기억하며 숫자를 누르면 터치 숫자판이 열립니다. 계근중량은 안정 예시값을 사용하며 **계근당 1장**으로 제한하는 제안입니다. 흔들림·연결 끊김·0 kg이면 계근 출력이 비활성화되고, 고정중량 출력은 유지합니다.

현재 계근중량이나 저울 설정 버튼을 눌러 시연 중량과 수신 상태를 바꿀 수 있습니다. COM2 / 2400 / 7E1은 현장 확인값 안내일 뿐 장치를 열지 않습니다. 시안의 계산·이력·생산량은 메모리에만 존재하며 새로고침하면 초기화됩니다. **실제 인쇄·서버 요청·저장·전송은 없습니다.**

운영 적용 단계에서는 서버의 내포장/외포장 구분, 기존 출력이력의 외포장 호환 처리, 재출력 스냅샷, 생산일보 집계를 일관되게 구현해야 합니다. 실제 저울 연결은 수신 중단·오래된 데이터, 단위·안정 신호, 용기무게를 별도로 검증해야 합니다. SM이 사용 중인 COM2를 동시에 열지 않습니다.
