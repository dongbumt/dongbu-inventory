# 내포장·외포장 라벨 터치화면 제안

2026-09-14 요청에 따른 **검토용 시안**입니다. 운영 중인 `label-print.html`, 원클릭 인쇄, 출력이력 저장 및 생산일보 전송 로직은 수정하지 않았습니다.

- 기준: 1280 × 1024 터치 모니터. 기존 `label-touch-proposals.html`의 1안 균형형(왼쪽 작업목록·계산기 / 오른쪽 출력)을 공통으로 사용합니다.
- 1안: 좌우 분리형. 내포장과 외포장을 각각 한 영역에 묶고 중량 빠른 선택을 제공합니다.
- 2안: 위아래 분리형. 내포장을 위, 외포장을 아래에 두고 각 행의 오른쪽에 출력 버튼을 배치합니다.
- 3안: 하단 큰 버튼형. 설정 영역 아래에 두 개의 큰 출력 버튼을 나란히 고정 배치합니다.
- 공통: 내포장(진공지)은 생산 집계 제외, 외포장(박스)만 생산량에 포함. 중량·매수는 각각 설정하고, 숫자 터치 시 화면 숫자판을 엽니다. 기존 라벨 인쇄 서식은 유지하는 제안입니다.
- 일반 버튼 높이 64px(시안 조정 60~64px), 계산기 키 약 76px, 출력 버튼 106px 이상을 기준으로 합니다. 좁은 미리보기 화면에서는 읽을 수 있도록 재배치합니다.

시안의 출력 수·생산량·계산기는 메모리 내 예시이며, 창을 새로고침하면 초기화됩니다. 내포장 인쇄 수는 작업 확인용 표시일 뿐 생산 실적이 아닙니다. 저울 설정 창의 COM2 / 2400 / 7E1은 현장 확인값을 안내하는 것으로, 이 시안에서는 장치를 열지 않습니다. 실제 인쇄·서버 요청·영구 저장은 없습니다.

선택한 안을 운영 화면에 적용하는 다음 단계에서는 내포장/외포장 구분을 서버 저장·생산일보 집계·재출력까지 일관되게 처리해야 합니다. 기존 출력이력은 이미 생산량으로 사용 중이므로 외포장으로 간주하는 하위호환 처리가 필요합니다. UI 시안만으로 운영 데이터 집계가 변경되지는 않습니다.

검증: `node tools/test-label-packaging-proposals.cjs` (Playwright 필요, `CHROME_PATH`로 브라우저 경로 지정 가능). 3안의 내포장 집계 제외, 외포장 누적, 독립 중량·매수, 터치 숫자판, 계산기, 작업별 상태, 생산완료 시연, 미리보기, 1280×1024 버튼 경계 및 1024/736/320px 반응형 배치를 검사합니다.
