# 라벨 출력 전용 화면 UI 시안

`label-touch-proposals.html`은 1280×1024 터치 모니터용 UI 비교 시안입니다.

- 1안 균형형: 왼쪽 작업목록·계산기, 오른쪽 출력 설정·최근 출력.
- 2안 저울 중심형: 큰 계근중량 표시, 중량 가져오기, 한 장씩 출력.
- 3안 단계형: 작업 확인 → 중량 설정 → 출력 확인.
- 모든 시안의 계산기는 왼쪽 아래에 있습니다. 1280px 폭에서 일반 버튼 높이는 기본 68px이며, 주 출력 버튼은 더 큽니다.
- 날짜·작업·중량·생산량은 예시입니다. 계산기, 작업 변경, 중량 선택, 단계 이동, 출력·전송 확인은 화면 안에서만 시연됩니다.
- 실제 저울·프린터·ERP·네트워크에 연결하지 않으며, 기존 운영 `label-print.html` 및 데이터베이스를 변경하지 않습니다.
- 저울의 제조사·모델·인터페이스와 수신 형식을 확인한 뒤 선택한 UI에 실제 연결을 별도로 구현해야 합니다. 미연결·불안정·오래된 수신값을 인쇄에 사용하지 않는 확인 절차가 필요합니다.

이 파일은 대화 안에서 세 안을 비교하기 위한 자체 포함 HTML 조각입니다. 디자인 조절 기능은 해당 기능을 지원하는 호스트에서만 표시되며, 없어도 시안의 기본 동작에는 영향이 없습니다.
