# 제품스펙 월사용량과 등록 제품 연결

`product_spec_monthly_usage_catalog` 마이그레이션은 `product_specs.monthly_usage`와 `material_product_id`를 추가합니다. 기존 스펙은 두 값 모두 NULL로 유지하며 자동으로 이름을 맞추거나 제품을 추측해 연결하지 않습니다.

- 월사용량은 KG 단위 선택 입력, 0 이상 999,999,999 이하이며 소수 여섯 자리까지 허용합니다. 미입력은 NULL, 입력한 0은 숫자 0으로 보존합니다.
- 재고량은 제품스펙별 참고값으로 직접 입력합니다. 월사용량과 같은 KG 단위와 입력 범위를 사용하고, 목록에서 확인·정렬할 수 있습니다.
- 화면의 ‘월사용량 합계’는 현재 거래처·유통사·검색 조건에 해당하고 월사용량이 입력된 스펙만 대상으로 품목명(원재료명)·브랜드·원산지 조합별로 묶습니다. 세 항목은 NFKC·대소문자·앞뒤 공백을 정규화해 비교하며, 다른 브랜드를 합치거나 원산지 별칭을 추측하지 않습니다. 거래처는 별도 집계 키로 사용하지 않습니다.
- 합계는 1KG의 백만분의 일 단위 정수로 계산해 소수 덧셈 오차를 방지합니다. 미입력 건수는 별도로 표시하고 해당 행은 합계표와 인쇄에서 제외합니다. 입력한 0은 포함합니다. 모두 미입력이면 빈 안내를 표시하고 합계표 인쇄를 비활성화하며, 상세 스펙 목록과 인쇄는 유지합니다.
- 합계표 열은 품목·브랜드·원산지·월사용량 합계 순서입니다. 각 열 제목은 클릭 또는 키보드로 오름차순/내림차순을 전환하며, 수량은 숫자 순서로 정렬합니다. 빈 브랜드/원산지는 양방향 정렬에서 마지막에 표시합니다. 상세 목록과 독립적인 정렬을 사용하고 새로고침 후에도 유지하며, 합계 행은 항상 마지막입니다.
- 상세 스펙 인쇄는 거래처·원재료·브랜드·원산지·세절스펙·내포장 스펙·외포장 스펙·월사용량 열을 출력하며, 유통사·비고·단가 열은 제외합니다. 유통사 필터는 출력 대상을 결정하며 머리글에 선택 조건으로 표시합니다. 합계표 인쇄는 품목·브랜드·원산지·월사용량 합계를 화면의 합계표 정렬 순서대로 출력하고, 머리글 건수는 월사용량 입력 스펙 수입니다. 두 출력 모두 현재 검색·선택 조건을 표시하는 A4 세로 문서입니다.

## 등록 제품 선택

원재료 검색은 기존 공용 품목 팝업을 `product-spec` 컨텍스트로 사용합니다. `labelProducts`에 등록된 활성 ‘제품’과 ‘원료육’을 유형 탭으로 전환해 선택합니다. 이미 연결된 품목을 다시 검색하면 해당 유형 탭으로 열립니다. 중지 품목과 다른 유형은 선택할 수 없습니다. 다른 메뉴의 팝업 유형 선택은 유지합니다. 품목명·품목코드·브랜드·원산지·포장규격으로 확인하며, 기존 5초 카탈로그 갱신도 그대로 적용됩니다.

선택하면 품목 이름·브랜드·원산지를 입력칸에 채우고 브랜드·원산지는 수정할 수 있습니다. `material_product_id`는 등록 품목 ID 문자열을 저장하며, 이름이 같은 품목도 서로 다른 등록 ID로 연결합니다. 서버는 현재 카탈로그를 확인하고 저장할 품목명을 결정합니다. 원료육도 신규 등록·수정·복사에 동일하게 사용합니다.

과거 직접 입력한 스펙은 이름을 변경하지 않으면 월사용량 등 다른 내용을 수정할 수 있습니다. 새 스펙과 복사 등록에서는 제품 또는 원료육을 선택해야 합니다. 이미 연결된 품목이 이후 중지·삭제되더라도 기존 연결과 이름을 유지한 스펙 수정은 허용하며, 새 등록이나 다른 품목으로 바꾸는 경우에는 활성 품목을 선택해야 합니다.

예전 탭의 API 요청이 새 필드를 생략하면 저장된 월사용량과 제품 연결을 보존합니다. 명시한 NULL은 월사용량을 비우는 의미입니다. 구버전 API의 신규 직접입력 요청은 호환을 위해 유지하지만 새 화면은 제품 선택을 확인합니다.

## 저장과 검증

원료육 허용은 기존 월사용량 마이그레이션 다음에 `supabase/migrations/20261116220712_product_spec_raw_materials.sql`을 적용합니다. 기존 레코드는 변경하지 않고 저장 함수의 품목 유형 검증만 확장합니다. 서버를 먼저 적용한 후 화면을 배포합니다.

기존 개인 세션·제품스펙 조회/등록/수정 권한과 revision 검사를 사용합니다. RLS와 직접 테이블 접근 차단을 유지하고, 수정 전후 값을 변경이력에 저장합니다. 기존 포장규격·유통 필드의 구버전 호환도 유지합니다.

`tools/check-product-spec-usage-db.ps1`은 브랜드 마이그레이션 설치 상태에서 재고량 마이그레이션과 가상 카탈로그·사용자·스펙을 검사한 뒤 모두 롤백합니다. 배포 후 `-Deployed`는 설치를 건너뛰고 동일한 검사를 롤백합니다. `tools/test-product-specs.cjs`는 공용 검색 팝업, 제품·원료육 저장 및 복사, 브랜드, 재고량, 정렬, 권한을 검사합니다. `tools/test-product-spec-print.cjs`는 선택 인쇄와 월사용량 합계의 PDF 출력을 검사합니다.

## 브랜드

`product_spec_brand` 마이그레이션은 스펙별 `brand`를 추가합니다. 브랜드는 선택 입력이며 200자까지 저장합니다. 원재료를 선택하면 등록 품목의 브랜드를 자동 입력하고, 기존 직접입력 스펙도 브랜드만 별도로 수정할 수 있습니다. 브랜드는 화면·상세 인쇄에서 원재료 바로 다음 열에 표시하며 검색·정렬·복사에도 반영합니다. 월사용량 합계도 품목명/브랜드/원산지별로 구분합니다.

기존 등록 품목 ID와 정확히 연결된 스펙만 마이그레이션 시 카탈로그 브랜드를 채웁니다. 직접입력 스펙에는 이름으로 브랜드를 추측하지 않습니다. 브랜드 외 기존 필드와 수정번호는 유지합니다. 이후 브랜드는 스펙별 저장값을 사용하므로 카탈로그 변경이 기존 브랜드를 덮어쓰지 않습니다. 구버전 요청이 브랜드를 생략하면 수정에서는 저장값을 보존하고, 신규 등록이나 다른 품목으로 변경할 때에는 연결한 품목의 브랜드를 기본값으로 사용합니다. 명시한 빈값 또는 NULL은 브랜드를 비웁니다.

## 유통사와 거래처 선택 인쇄

유통사를 먼저 선택하면 해당 유통사의 거래처만 체크박스로 표시하며 기본값은 전체 선택입니다. 전체 선택 체크박스로 모두 선택하거나 해제하고, 개별 거래처를 해제해 제외할 수 있습니다. 전체 유통사에서도 같은 방식으로 여러 거래처를 고를 수 있습니다. 검색어는 거래처 체크 상태를 바꾸지 않고 추가 조건으로 적용합니다.

화면 목록·월사용량 합계·상세 인쇄·합계표 인쇄에 같은 선택 조건을 사용합니다. 일부만 선택하면 전체 선택 체크박스에 부분 선택 상태를 표시합니다. 아무 거래처도 선택하지 않으면 목록과 합계가 비고 두 인쇄 버튼을 비활성화합니다. 인쇄물에는 선택한 거래처와 유통사를 표시합니다.

유통사를 바꾸거나 검색을 초기화하면 거래처를 전체 선택합니다. 같은 유통사에서 새로고침할 때는 명시한 개별 선택을 유지하며, 선택했던 거래처가 사라져도 다른 거래처로 출력 범위를 넓히지 않습니다. 세션이 바뀌면 이전 거래처 선택과 목록을 비웁니다.
